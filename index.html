📘 Guía Práctica: Superposición de Fuerzas Concurrentes a un Punto

Objetivo: Aprender a determinar la fuerza resultante de un sistema de fuerzas que actúan sobre un mismo punto (fuerzas concurrentes), utilizando métodos gráficos y analíticos.

1. Conceptos Fundamentales

1.1 ¿Qué es una fuerza concurrente?

Una fuerza es una magnitud vectorial que describe la interacción entre dos cuerpos, caracterizada por:

  • Magnitud (módulo): Intensidad de la fuerza, medida en Newtons (N).
  • Dirección: Línea de acción sobre la que actúa la fuerza.
  • Sentido: Hacia dónde apunta la fuerza a lo largo de su dirección.
  • Punto de aplicación: Lugar donde se aplica la fuerza.

Las fuerzas concurrentes son aquellas cuyas líneas de acción se intersectan en un mismo punto. Todas las fuerzas actúan sobre un mismo cuerpo y comparten un punto común de aplicación.

1.2 Principio de Superposición

El efecto de varias fuerzas concurrentes es equivalente al efecto de una única fuerza llamada fuerza resultante (R), que se obtiene sumando vectorialmente todas las fuerzas del sistema.

R⃗ = F⃗₁ + F⃗₂ + F⃗₃ + ... + F⃗ₙ = Σ F⃗ᵢ

1.3 Equilibrio

Un sistema de fuerzas concurrentes está en equilibrio cuando su resultante es cero:

R⃗ = 0 → Σ F⃗ₓ = 0 y Σ F⃗ᵧ = 0

2. Métodos para Encontrar la Resultante

2.1 Método Gráfico: Regla del Paralelogramo

Para dos fuerzas concurrentes:

  1. Dibujar ambos vectores con su punto de aplicación común.
  2. Completar el paralelogramo trazando líneas paralelas a cada fuerza.
  3. La diagonal del paralelogramo que parte del punto común es la resultante R.

2.2 Método Gráfico: Polígono de Fuerzas

Para más de dos fuerzas:

  1. Dibujar el primer vector F₁ desde un punto arbitrario.
  2. Dibujar el segundo vector F₂ desde la punta de F₁.
  3. Continuar con F₃, F₄, etc., cada uno desde la punta del anterior.
  4. La resultante R va desde el origen de F₁ hasta la punta del último vector.

2.3 Método Analítico: Descomposición en Componentes

Este es el método más preciso y se usa cuando se conocen las magnitudes y ángulos.

Pasos del método analítico:
Paso 1: Establecer un sistema de ejes coordenados (X, Y) con origen en el punto de concurrencia.
Paso 2: Descomponer cada fuerza en sus componentes horizontal (Fₓ) y vertical (Fᵧ):
Fₓ = F · cos(θ)
Fᵧ = F · sen(θ)
Donde θ es el ángulo medido desde el eje X positivo en sentido antihorario.
Paso 3: Sumar algebraicamente todas las componentes:
Rₓ = Σ Fₓᵢ
Rᵧ = Σ Fᵧᵢ
Paso 4: Calcular la magnitud de la resultante:
R = √(Rₓ² + Rᵧ²)
Paso 5: Calcular la dirección de la resultante:
θᵣ = arctan(Rᵧ / Rₓ)
Nota: Ajustar el cuadrante según los signos de Rₓ y Rᵧ.

3. Tabla de Signos por Cuadrante

Cuadrante Rₓ Rᵧ Ángulo θᵣ
I (0° - 90°) + + θᵣ = arctan(Rᵧ/Rₓ)
II (90° - 180°) - + θᵣ = 180° - arctan(|Rᵧ/Rₓ|)
III (180° - 270°) - - θᵣ = 180° + arctan(|Rᵧ/Rₓ|)
IV (270° - 360°) + - θᵣ = 360° - arctan(|Rᵧ/Rₓ|)

4. Ejemplo Resuelto

📌 Problema: Tres fuerzas actúan sobre un punto:
  • F₁ = 100 N a 30° respecto al eje X positivo
  • F₂ = 150 N a 120° respecto al eje X positivo
  • F₃ = 80 N a 240° respecto al eje X positivo
Determinar: La fuerza resultante (magnitud y dirección).
✅ Solución paso a paso:

Paso 1: Descomponer cada fuerza

Fuerza Magnitud Ángulo Fₓ = F·cos(θ) Fᵧ = F·sen(θ)
F₁ 100 N 30° 100·cos(30°) = 86.60 N 100·sen(30°) = 50.00 N
F₂ 150 N 120° 150·cos(120°) = -75.00 N 150·sen(120°) = 129.90 N
F₃ 80 N 240° 80·cos(240°) = -40.00 N 80·sen(240°) = -69.28 N
Σ (Sumas) Rₓ = -28.40 N Rᵧ = 110.62 N

Paso 2: Calcular la magnitud de R

R = √((-28.40)² + (110.62)²) = √(806.56 + 12236.78) = √13043.34
R ≈ 114.2 N

Paso 3: Calcular la dirección de R

Como Rₓ es negativo y Rᵧ es positivo, la resultante está en el cuadrante II.

θᵣ = arctan(110.62 / 28.40) = arctan(3.895) = 75.6°
θᵣ = 180° - 75.6° = 104.4° (desde el eje X positivo)

Respuesta:

R = 114.2 N a 104.4° respecto al eje X positivo (antihorario)

6. Fórmulas de Resumen

Componentes: Fₓ = F·cos(θ)   |   Fᵧ = F·sen(θ)
Resultante: R = √(Rₓ² + Rᵧ²)
Dirección: θᵣ = arctan(Rᵧ/Rₓ) → ajustar cuadrante
Equilibrio: ΣFₓ = 0  y  ΣFᵧ = 0

8. Consejos Prácticos

  • 🔹 Siempre dibuja un diagrama antes de calcular. Te ayuda a visualizar cuadrantes y signos.
  • 🔹 Verifica los signos de las componentes según el cuadrante del ángulo.
  • 🔹 Usa calculadora en modo grados (DEG), no en radianes (RAD).
  • 🔹 Redondea al final, no en pasos intermedios, para evitar errores de acumulación.
  • 🔹 Comprueba tu resultado: la resultante debe estar "entre" las fuerzas originales en el diagrama.
  • 🔹 Para problemas de equilibrio, recuerda que la fuerza de equilibrio es igual y opuesta a la resultante.
  • 🔹 Usa la calculadora de esta guía para verificar tus ejercicios manualmente.
